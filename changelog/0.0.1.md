The first public release of `@glass-sdk/liquid-glass`: glass surfaces and controls for React, the web, and Electron. Clear and Regular materials refract live content in light and dark appearances.

```sh
npm install @glass-sdk/liquid-glass@~0.0.1
```

```tsx
import { GlassScene, GlassContent, GlassSurface, GlassButton } from "@glass-sdk/liquid-glass";
import "@glass-sdk/liquid-glass/styles.css";

<GlassScene material="regular" appearance="light" style={{ height: 320 }}>
  <GlassContent>
    <img src="/landscape.jpg" alt="Mountain lake" />
  </GlassContent>
  <GlassSurface radius={28} style={{ position: "absolute", left: 24, top: 100, padding: 20 }}>
    <GlassButton onClick={save}>Save</GlassButton>
  </GlassSurface>
</GlassScene>;
```

### New

- `GlassScene` and `GlassContent` set up a scene and its live background. Text, SVG, and images in the content layer stay live.
- `GlassSurface` and `GlassButton`, with `material`, `appearance`, `radius`, `refraction`, `tint`, `interactive`, `fluid`, `morphFrom`, `morph`, and `motion` props. Set defaults on the scene and override them per surface.
- Controls built on Base UI: `GlassToolbar` and its buttons, links, groups, and spacers; `GlassTabs` and composable tab parts; `GlassMenu` with submenus, groups, checkbox and radio items; `GlassSlider` and `GlassSwitch`.
- `GlassProgressiveBlur` softens content at an edge, and `GlassScrollEdges` blurs the edges of a scrolling viewport.
- `GlassShape`, `GlassShapeContainer`, and `GlassCorner` for continuous corners and concentric, container-relative geometry. `GlassForeground` and `useGlassForeground` let higher glass refract ordinary DOM.
- `@glass-sdk/liquid-glass/dom` drives scenes without React through `createGlassScene()`. `/core` and `/gpu` expose the geometry, material, and map-rendering APIs.
- Reduced-motion preferences always apply, and reduced transparency and forced colors turn the blur effects off.

Rendering needs React 19 or later for the components, HTTPS or localhost, and a WebGPU adapter. Safari has known rendering issues in this release.
